## 1. 执行摘要

### 1.1 产品概述

Kingsway Video 展会版是一个基于外贸线下展会场景的视频展示和沟通工具。外贸客户可以将上传的视频分门别类，后台自动生成视频独立站（无需编程），生成二维码印在名片上。海外采购商扫码后可以像 TikTok 一样沉浸式滑动浏览视频，收藏感兴趣的内容，一键唤起 WhatsApp 询盘。

### 1.2 核心价值主张

- **解决展位有限问题** - 通过线上视频展示更多产品
- **解决人力不足问题** - 视频自动接待，客户可带回家继续沟通
- **解决兴趣追踪问题** - 收藏数据通过 URL 传递给业务员
- **解决访问问题** - 国内外都能访问，YouTube 被墙的替代方案

### 1.3 业务目标

| 目标 | 衡量指标 | 目标值 |
|------|----------|--------|
| 提升付费转化率 | 使用展会版的客户数量 | 持续增长 |
| 增加收入 | 付费客户占比 | 提升 |
| 差异化竞争 | 客户慕名而来注册 | 成为获客引擎 |

### 1.4 成功标准

- 更多客户因为展会版慕名而来注册 Kingsway Video
- 客户通过展会版获得更多询盘和订单
- 付费转化率提升
- 展会版成为产品的核心竞争优势

## 2. 用户画像

### 2.1 主要用户（付费客户）

**外贸业务员 / 外贸厂商**

| 属性 | 描述 |
|------|------|
| 行业 | 制造业 B 端（源头工厂） |
| 行业细分 | 专业灯光、手机壳 DIY 设备、各类制造业 |
| 技术能力 | IT 技术能力弱，需要零代码、极简操作 |
| 营销能力 | 普遍缺乏营销能力 |
| 现有资源 | 有视频内容，但缺乏有效的展示和分发渠道 |
| 痛点 | 展位有限、人力不足、客户兴趣难追踪 |

**核心需求：**
1. 零代码快速创建视频独立站
2. 生成二维码方便分发
3. 了解访客行为数据
4. 快速获得询盘

### 2.2 次要用户（访客）

**海外采购商**

| 属性 | 描述 |
|------|------|
| 设备 | 主要使用手机或平板 |
| 访问方式 | 扫码访问 |
| 行为特征 | 需要快速浏览和筛选产品 |
| 沟通偏好 | WhatsApp、邮件 |
| 痛点 | 展会时间有限，无法看完所有产品 |

**核心需求：**
1. 国内外都能播放视频
2. 加载速度快
3. 沉浸式浏览体验
4. 一键 WhatsApp 沟通
5. 收藏感兴趣的产品

## 3. 功能需求 (Functional Requirements)

### 3.1 访客端功能

#### FR-001: 页面布局

**优先级：** Must Have

**描述：**
访客端首页采用三栏布局：顶部横向一级导航栏（Logo、搜索、一级导航菜单如 Home/About）、左侧内页锚点导航（视频分类文字链接）、主体视频列表区域。右上角显示主题颜色切换和语种切换按钮。

所有分类的视频在同一页面展示，左侧导航点击可跳转到对应分类锚点。

**界面语言：** 全部使用英文。

**验收标准：**
- [ ] 顶部导航栏固定显示 Logo、搜索框、横向一级导航菜单
- [ ] 右上角显示主题颜色切换按钮
- [ ] 右上角显示语种切换按钮（在主题颜色切换旁边）
- [ ] 左侧导航显示所有视频分类，使用文字链接（非图标）
- [ ] 点击左侧导航可平滑滚动到对应分类区域
- [ ] 布局响应式适配桌面和移动端
- [ ] 移动端左侧导航可收起/展开
- [ ] 所有界面文字使用英文

**Bug 修复：**
- [ ] 修复 Popover 播放时左侧导航锚文本失效的问题
- [ ] 修复 Popover 播放时左侧导航样式显示异常的问题

**依赖：** 无

#### FR-002: 视频列表展示

**优先级：** Must Have

**描述：**
视频卡片根据视频方向采用不同样式：竖屏视频的标题显示在封面图片内（底部），横屏视频的标题显示在封面图片外（下方）。所有视频的播放按钮（▶ icon）统一显示在封面右上角。

**分类标题样式：**
- 每个分类标题下方显示小段文案："X videos in this category"（单独一行）
- 分类之间不显示横线分隔（取消横线）
- 通过空白间距区分不同分类

**收藏按钮：**
- 收藏按钮位于视频封面右上角
- 收藏按钮紧挨着播放按钮下方垂直排列
- 收藏按钮尺寸与播放按钮相同

**移动端特殊布局：**
- 竖屏视频：水平滚动显示，默认显示 1.5 个卡片
- 横屏视频：一行显示一个，向下滚动查看更多

**验收标准：**
- [ ] 分类标题下方显示 "X videos in this category" 文案
- [ ] 分类之间不显示横线分隔
- [ ] 分类之间通过空白间距区分
- [ ] 竖屏视频标题在封面内底部显示
- [ ] 横屏视频标题在封面下方显示
- [ ] 播放 icon 在封面右上角显示
- [ ] 收藏按钮在封面右上角，播放按钮下方
- [ ] 收藏按钮尺寸与播放按钮相同
- [ ] 收藏按钮状态正确（空心/实心）
- [ ] 点击收藏按钮可切换收藏状态
- [ ] 视频卡片显示封面、标题、时长
- [ ] 视频卡片网格布局自适应（桌面端）
- [ ] 移动端竖屏视频水平滚动，默认显示 1.5 个卡片
- [ ] 移动端横屏视频一行显示一个，向下滚动查看
- [ ] 点击视频卡片弹出播放 Popover

**依赖：** FR-001, FR-007

#### FR-003: Popover 视频播放

**优先级：** Must Have

**描述：**
点击视频卡片后，弹出 Popover 浮层播放视频。

**桌面端：** Popover 内容在屏幕中央显示，非全屏宽度，确保视频在不同设备尺寸下都能完整显示。PC 端上下切换按钮位于视频右边缘。

**移动端：** 视频铺满整个屏幕，保持沉浸感。不显示视频排序（如 1/3）。

**验收标准：**
- [ ] 点击视频卡片弹出 Popover
- [ ] 桌面端 Popover 内容居中显示，非全屏宽度
- [ ] 移动端 Popover 视频铺满整个屏幕
- [ ] 视频自动播放
- [ ] PC 端上下切换按钮在视频右边缘
- [ ] 点击 Popover 外部区域可关闭
- [ ] 左上角显示返回按钮
- [ ] 不显示视频排序（如 1/3）

**依赖：** FR-001, FR-002

在 Popover 播放状态下，支持 TikTok 式上下滑动切换视频。手机端通过手势滑动切换，PC 端通过点击右侧边缘的上下按钮切换。切换时视频自动播放，动画流畅。

**验收标准：**
- [ ] 手机端支持上下滑动切换视频
- [ ] PC 端支持点击按钮切换视频
- [ ] 切换动画流畅（≥60fps）
- [ ] 切换后新视频自动播放
- [ ] 切换后滚动到对应分类区域（关闭 Popover 时）

**依赖：** FR-003

- [ ] 点击浮层空白区域可关闭

#### FR-007: 收藏功能

**优先级：** Must Have

**描述：**
访客可以收藏感兴趣的视频，收藏数据存储在浏览器 localStorage。收藏的视频 ID 拼接到 URL 参数中，可通过 URL 分享收藏列表。

**收藏列表始终显示在页面底部**（即使没有收藏），采用悬浮按钮形式，不占用整个页面宽度。收藏列表按钮与 WhatsApp 询盘按钮并列显示在底部悬浮栏中。点击收藏列表按钮可展开查看已收藏的视频。

页面主体内容保持屏幕中央显示，不被底部悬浮栏遮挡。

**验收标准：**
- [ ] 点击视频卡片左上角收藏按钮添加/取消收藏
- [ ] 点击 Popover 右侧挂件收藏按钮添加/取消收藏
- [ ] 收藏数据存储在 localStorage
- [ ] 收藏状态在页面刷新后保持
- [ ] URL 参数包含收藏视频 ID（?favorites=id1,id2,id3）
- [ ] 打开带有收藏参数的 URL 自动加载收藏列表
- [ ] 收藏列表按钮固定悬浮在页面底部
- [ ] 收藏列表按钮与 WhatsApp 询盘按钮并列显示
- [ ] 收藏列表采用悬浮按钮形式（不占用整个页面宽度）
- [ ] 点击收藏列表按钮展开查看已收藏的视频缩略图
- [ ] 无收藏时显示空状态提示
- [ ] 收藏列表中的视频可点击播放
- [ ] 收藏数量限制（最多 20 个）
- [ ] 页面主体内容保持屏幕中央显示

**依赖：** FR-001, FR-005

#### FR-009: 询盘入口

**优先级：** Must Have

**描述：**
提供 WhatsApp 和邮件两种询盘方式。

**底部悬浮栏：** 收藏列表按钮与 WhatsApp 询盘按钮并列显示在页面底部，采用悬浮按钮形式（不占用整个页面宽度）。WhatsApp 询盘按钮只使用图标（💬），不显示文字。点击 WhatsApp 按钮唤起 WhatsApp 应用，问候语自动携带收藏列表 URL 和用户填写的联系信息。

**邮件询盘**同样携带收藏列表信息和用户填写的联系信息。

**验收标准：**
- [ ] 底部悬浮栏包含收藏列表按钮和 WhatsApp 询盘按钮
- [ ] 两个按钮并列显示在底部悬浮栏中
- [ ] 悬浮栏采用悬浮按钮形式（不占用整个页面宽度）
- [ ] WhatsApp 询盘按钮只使用图标（💬），不显示"WhatsApp"文字
- [ ] 点击 WhatsApp 按钮唤起 WhatsApp 应用
- [ ] 问候语包含收藏列表 URL
- [ ] 问候语包含用户填写的联系信息（姓名、邮箱、职位、国家）
- [ ] 问候语格式："Hi, I'm {姓名} from {公司/职位}, {国家}. I'm interested in: {视频标题列表}. View my favorites: {URL}. Contact me: {邮箱}"
- [ ] 邮件询盘同样携带收藏信息和联系信息
- [ ] 无收藏时也能发起询盘

### 3.2 管理端功能

- [ ] 显示已绑定的域名列表

#### FR-016: 导航配置管理

**优先级：** Must Have

**描述：**
管理端支持对站点导航进行可视化配置，支持多级结构（父子导航）以及灵活的跳转规则（自定义链接或内部页面）。

**验收标准：**
- [ ] **导航操作**：
    - 支持新建一级导航。
    - 支持调整导航显示顺序（拖拽调整）。
    - 支持删除导航项。
- [ ] **导航属性设置（右侧面板）**：
    - **导航名称**：支持自定义显示名称。
    - **导航类型**：可选“父级导航”或“链接”。
- [ ] **跳转规则配置**：
    - **链接类型**：如果导航类型为“链接”，可选择“自定义链接”或“选择页面”。
    - **自定义链接**：输入以 http/https 开头的完整 URL。
    - **选择页面**：从系统已有的页面列表中选择目标页面。
- [ ] **多级导航（父子结构）**：
    - 如果类型为“父级导航”，支持在下方添加/管理子导航。
    - 子导航同样支持配置“自定义链接”或“选择页面”。
    - 提供弹窗式交互（Add Sub-nav Modal）用于新增子项。

**依赖：** FR-011

## 4. 非功能需求 (Non-Functional Requirements)

### 4.1 性能需求

#### NFR-001: 视频加载性能

**优先级：** Must Have

**描述：**
视频首帧加载时间应小于 2 秒，确保用户点击后快速看到视频内容。

**验收标准：**
- [ ] 视频首帧加载时间 < 2 秒（WiFi 环境）
- [ ] 视频首帧加载时间 < 4 秒（4G 网络）
- [ ] 支持视频预加载策略

**依据：** 用户期望快速加载，优于 YouTube

---

#### NFR-002: 页面加载性能

## 11. 假设与约束

### 11.1 关键假设

- 访客设备支持现代 Web 技术（CSS Grid, Scroll Snap, LocalStorage）
- 网络环境能支持视频流畅播放
- WhatsApp 是海外采购商的主要沟通工具
- 访客愿意通过扫码方式访问视频内容
- 业务员有基本的电脑操作能力

### 11.2 技术约束

- 基于现有"线上视频独立站版本"改造
- 通过导入方式启用展会版（非切换模板）
- 视频和分类数据可从线上版本复用
- Demo 阶段使用 Mock 数据

### 11.3 业务约束

- 目标用户是制造业 B 端外贸厂商
- 主要场景是线下展会
- 访客匿名访问，不收集个人信息

## 12. 关键用户流程

### 12.1 访客浏览流程

```
1. 访客扫码进入展会版站点
2. 浏览视频列表，点击感兴趣的视频
3. Popover 弹出播放视频
4. 上下滑动切换视频，继续浏览
5. 收藏感兴趣的视频
6. 点击 WhatsApp 询盘按钮
7. WhatsApp 唤起，自动携带收藏列表 URL
8. 发送消息给业务员
```

### 12.2 业务员创建流程

```
1. 业务员登录管理端
2. 选择"导入数据"，选择现有视频独立站
3. 预览导入内容，确认导入
4. 生成展会版站点
5. 自定义 Logo 和主题色（可选）
6. 生成二维码并下载
7. 打印二维码在名片上
8. 在展会分发名片
9. 查看行为看板，了解访客数据
```
