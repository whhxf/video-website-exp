# Kingsway 视频独立站 Demo — 需求说明书

## 产品定义

一个链接，让客户沉浸式刷完你的所有视频，在看的过程中建立信任，在兴趣最高点完成询盘转化。

## 目标用户

| 角色 | 场景 | 核心诉求 |
|------|------|---------|
| **外贸业务员**（发送方） | 展会跟进、开发信、WhatsApp 沟通时发链接给客户 | 一个链接搞定所有展示，不用来回发文件 |
| **海外采购商**（接收方） | 手机上打开链接，快速了解供应商 | 快速判断这家供应商是否靠谱 |

## 核心用户旅程

> 业务员在 WhatsApp 上发了一个链接 → 客户点开 → 上下滑动刷了 8 个视频（工厂巡展 → 产品线 → 质检流程 → 客户案例 → 团队介绍）→ 对第三个产品视频产生兴趣 → 点击视频下方的 "Inquiry" 按钮 → 填写名字和邮箱 → 询盘发送。整个过程 3 分钟，客户没有离开过这个页面，没有看过任何竞品广告。

## 功能需求

### F1. 视频信息流（P0 — 没有这个就没有产品）

**业务场景**：客户打开链接，像刷 TikTok 一样连续看你的视频，不需要点来点去。

- 竖屏全屏布局，上下滑动切换视频（CSS scroll-snap 或 JS touch）
- 当前视频自动播放，离开视口暂停
- 每个视频卡片包含：视频播放区、标题、描述
- 进度条显示当前视频播放进度
- 视频封面图在加载前展示
- 右侧交互栏：点赞、分享、询盘快捷入口

**Demo 要求**：至少 6 个不同类别的视频卡片，覆盖工厂、产品、证书、案例。

### F2. 视频内询盘转化（P0 — 价值证明点）

**业务场景**：客户看产品视频时产生兴趣，在兴趣最浓的这一刻就能发起联系，不需要跳转、不需要找联系方式。

- 每个视频卡片底部有操作按钮组：**WhatsApp**、**Inquiry Form**、**Email**
- WhatsApp 按钮：点击直接打开 `wa.me` 链接，预填消息（告知是哪个视频）
- Inquiry 按钮：弹出内嵌表单（不跳页），字段：Name、Email、Phone、Message
- 提交后展示成功提示，表单数据可在 Demo 中 console.log 模拟
- 按钮颜色、文案可配置（体现品牌自定义能力）

### F3. 品牌信任区（P0 — 信任建立）

**业务场景**：客户刷完视频后，需要一个地方「汇总确认」这家公司的实力。不是纯视频流，而是有结构化信息做信任收口。

- 页面顶部固定品牌 Logo + 公司名
- 滑到最后一个视频后，出现「公司实力」汇总卡片：
  - 关键数字（成立年限、客户数、出口国家数、证书数）
  - 主要客户/合作品牌 logo 墙
  - 一句话价值主张
- 联系方式汇总区：WhatsApp、Email、官网链接

### F4. 视频分类导航（P1 — 快速跳转）

**业务场景**：客户对某个品类特别感兴趣（比如只想看某类产品），不想刷完所有视频。需要快速定位。

- 顶部或侧边的分类标签栏：All / Factory / Products / Quality / Cases / Team
- 点击标签，视频流自动滚动到对应分类
- 当前分类高亮

### F5. 多语言切换（P1 — 全球客户）

**业务场景**：同一个链接发给西班牙客户和沙特客户，他们看到的是各自语言的界面。

- 语言切换按钮（顶部右上角）
- Demo 至少支持：EN / 中文 / Español（实际翻译可精简，演示切换效果即可）
- 切换后：界面文案、视频标题、CTA 按钮文字全部切换

### F6. 移动端优先的响应式设计（P0 — 硬约束）

**业务场景**：客户在 WhatsApp/微信里收到链接，用手机打开。这是 90% 的流量来源。

- 手机端：竖屏全屏滑动，TikTok 式体验
- 桌面端：居中单列布局，模拟手机视口（最大宽度 480px），两侧留白
- 桌面端支持键盘上下键切换视频、鼠标滚轮

### F7. SEO 结构化基础（P1 — 体现产品差异化）

**业务场景**：视频独立站的每个视频会被 Google 收录。页面需要具备基础的 SEO 结构。

- 每个视频有独立锚点 ID（`#video-1`）
- 语义化 HTML：`<video>` + `<article>` + `<h1>`-`<h3>`
- JSON-LD 结构化数据（VideoObject schema）内嵌在 `<head>` 中
- Meta title / description 完整

### F8. 视频播放控制与性能（P1）

- 视频懒加载：只有进入视口的视频才加载资源
- 视频封面图（poster）先展示，点击或自动播放
- 桌面端鼠标悬停显示播放/暂停控件
- 弱网环境下封面图优先展示

```
│                          │
│  视频 1: 工厂巡展         │  ← 当前可见
│  ┌──────────────────────┐│
│  │    [video player]    ││
│  │ 进度条               ││

│  │ [WhatsApp] [Inquiry] ││
│  └──────────────────────┘│
│                          │
│  视频 2: 产品展示         │  ← 下滑进入
│  ...                     │
│                          │
│  视频 3-6 ...            │
│                          │
│  信任汇总卡片             │  ← 最后一个

```

## Demo 不做的事

- 不接真实后端（表单提交用 console.log 模拟）
- 不做用户登录/注册
- 不做视频上传功能（视频用 Kingsway 现有 CDN 链接或示例视频）
- 不做数据统计面板

## 技术方案

纯静态 HTML + CSS + Vanilla JS，单文件，可直接在浏览器打开。
