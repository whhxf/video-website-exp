# Design Context — RayLED Demo Sales Deck

## Users
外贸工厂老板/外贸公司决策者——他们在手机上收到链接，需要快速判断 Kingsway 这个产品是否值得购买。看 demo 的场景通常是碎片时间（展会间隙、WhatsApp 聊天中）。

## Brand Personality
- **信任 + 友好 + 国际**：不是冷冰冰的工业感，而是「这个供应商靠谱、好合作」
- 参考 TikTok 的沉浸式内容消费体验 + 小红书的精致克制
- 看起来应该像一个真正的、已经上线运营的产品，而不是「演示页面」

## Aesthetic Direction
- **Dark mode** — 视频优先的沉浸式体验（TikTok 基因）
- **干净、现代、精致** — 小红书式的克制排版
- 不要 LED 炫彩、不要赛博朋克、不要过度科技感。这是给外贸老板看的，不是给极客看的

## Design Principles
1. **像一个真实产品** — 每个细节都应该让人相信这是已上线、有人用的产品
2. **品牌感优先于功能感** — logo、排版、间距的精緻度比功能多寡更重要
3. **克制** — 少即是多，不要为了证明「设计过」而堆装饰
4. **移动端原生感** — 看起来像 iOS/Android 上的一个高质量 app，不是网页
