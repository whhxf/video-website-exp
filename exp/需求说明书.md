# "SmartTrust Video Hub" 展会版需求说明书

## 1. 项目定位与核心价值

### 1.1 项目背景
**目标展会：** Prolight + Sound 广州国际专业灯光音响展、上海国际舞台灯光展等

**行业痛点：** 舞台灯光行业产品专业性强，买家（演出公司、租赁公司、剧院）需要看到灯具的实际效果才能判断品质。传统展会上，受限于展位空间和光线条件，难以完整呈现灯光效果。访客离开展位后，无法回顾产品细节。

### 1.2 核心价值主张

| 核心特性 | 用户价值 | 业务价值 |
|----------|----------|----------|
| 🎬 **视频信任构建** | 访客通过观看工厂产线、研发团队、大型演出案例视频，快速建立信任感 | 降低决策门槛，提升询盘质量 |
| 🔍 **产品探索与收藏** | 访客快速浏览灯具产品，观看灯光效果视频，一键收藏感兴趣的型号 | 捕捉用户兴趣点，精准识别需求 |
| 📱 **WhatsApp 即时沟通** | 访客一键将收藏分享给现场销售，即时开启深度沟通 | 缩短从兴趣到对话的路径 |
| 🖨️ **销售打印工具** | 销售打印访客收藏页，现场纸笔补充，附带沟通二维码 | 线上线下无缝衔接，持续跟进 |

## 2. 核心用户故事 (User Stories)

### 故事 A：访客 Mike — "视频建立信任"
*   **背景：** Mike 是一位来自迪拜的演出租赁公司采购经理，首次来到这家舞台灯光工厂的展位。
*   **场景：** 他扫描展位的二维码进入网页，首先看到的是一段 30 秒的工厂全景视频。
*   **行为：** 
    *   观看「自动化生产线」视频 → 了解SMT贴片、老化测试等专业产线
    *   观看「研发团队」视频 → 看到光学工程师调试灯具的专业场景
    *   观看「演唱会案例」视频 → 看到某知名歌手演唱会使用该品牌灯具的震撼效果
*   **结果：** Mike 从"随便看看"变成"这家工厂很专业"，主动开始浏览产品。

---

### 故事 B：访客 Sarah — "快速收藏感兴趣的产品"
*   **背景：** Sarah 是欧洲一家剧院的技术总监，她需要在一天内考察 30 个舞台灯光展位。
*   **场景：** 在工厂展位，她快速浏览产品列表。
*   **行为：** 
    *   滑动浏览产品卡片：摇头光束灯、LED 帕灯、追光灯、控台...
    *   点击「350W 摇头光束灯」，观看灯光效果视频，查看光学参数
    *   点击「❤️ 收藏」按钮，将 5 款感兴趣的灯具添加到收藏夹
*   **结果：** Sarah 在 3 分钟内完成初筛，收藏了最感兴趣的产品，继续赶往下一个展位。

---

### 故事 C：访客 Sarah — "WhatsApp 分享给销售"
*   **背景：** Sarah 逛完展馆后，想和上午那家工厂的销售深入聊聊灯具配置方案。
*   **场景：** 她打开收藏页，看到收藏的 5 款灯具整齐排列。
*   **行为：** 
    *   点击「📤 分享给销售」按钮
    *   弹出简短表单，填写：称呼 "Sarah"、角色 "Technical Director"、国家 "Germany"
    *   点击确认，系统生成带客户信息的收藏页链接
    *   一键跳转 WhatsApp，消息已预填好："Hi, I'm Sarah (Technical Director) from Germany. I'm interested in these products: [收藏页链接]"
*   **结果：** 展位销售小李的手机收到消息，立即看到客户背景信息，打开链接查看收藏的灯具型号，开始针对性沟通。

---

### 故事 D：销售小李 — "打印收藏页，现场补充信息"
*   **背景：** Sarah 来到展位，小李想当面深入了解她的剧院需求。
*   **场景：** 小李在手机上打开 Sarah 的收藏页链接。
*   **行为：** 
    *   点击「🖨️ 打印版」按钮，页面切换为打印友好布局
    *   连接展位打印机，将收藏页打印成纸质版
    *   在打印纸上用笔标注：Sarah 的剧院规模、预算范围、需要的数量、对控台的兼容性要求
    *   打印纸底部自动带有小李的 WhatsApp 二维码和联系方式
*   **结果：** Sarah 带走这张纸，回到酒店扫码即可继续和小李沟通，上面还有她的需求备注。

---

### 故事 E：销售经理 张总 — "数据复盘与跟进"
*   **背景：** Prolight + Sound 展会结束，张总需要安排团队跟进。
*   **场景：** 张总查看后台数据看板。
*   **行为：** 
    *   查看"收藏热度榜"：350W 摇头光束灯被收藏 47 次排名第一
    *   查看"视频观看榜"：演唱会案例视频完播率高达 78%
    *   导出"高意向客户列表"：收藏 3+ 产品且分享给销售的访客
*   **结果：** 张总精准分配跟进资源，来自迪拜的 Mike 和欧洲的 Sarah 由资深销售重点跟进。

## 5. 技术实现方案

### 5.1 前端技术栈

| 模块 | 技术选型 | 说明 |
|------|----------|------|
| **页面框架** | HTML5 + Tailwind CSS | 轻量、快速、响应式 |
| **视频播放** | HTML5 `<video>` + CDN | 流畅加载 |
| **收藏功能** | LocalStorage + URL State | 无需登录，数据持久化 |
| **分享功能** | URL 参数编码收藏列表 | 链接即数据 |
| **打印样式** | CSS `@media print` | 打印友好布局 |
| **二维码** | QRCode.js | 客户端生成销售二维码 |

// 添加收藏
function addFavorite(productId) {
  const favorites = JSON.parse(localStorage.getItem('favorites') || '[]');
  if (!favorites.includes(productId)) {
    favorites.push(productId);
    localStorage.setItem('favorites', JSON.stringify(favorites));
    updateFavoriteCount();
  }
}

// 更新收藏数量显示
function updateFavoriteCount() {
  const favorites = JSON.parse(localStorage.getItem('favorites') || '[]');
  document.getElementById('favorite-count').textContent = favorites.length;
}

function shareToWhatsApp(customerInfo) {
  const favorites = JSON.parse(localStorage.getItem('favorites') || '[]');
  const productNames = favorites.map(id => products.find(p => p.id === id)?.name).join(', ');
  
  // 构建包含客户信息的消息
  let message = 'Hi';
  if (customerInfo.name) {
    message += `, I'm ${customerInfo.name}`;
    if (customerInfo.role) message += ` (${customerInfo.role})`;
    if (customerInfo.country) message += ` from ${customerInfo.country}`;
  }
  message += `. I visited your booth at Prolight+Sound.\n`;
  message += `I'm interested in: ${productNames}\n`;
  message += `My favorites: ${window.location.origin}/favorites?ids=${favorites.join(',')}`;
  
  const whatsappUrl = `https://wa.me/8613800138000?text=${encodeURIComponent(message)}`;
  window.open(whatsappUrl, '_blank');
}

// 客户信息表单数据
const customerInfo = {
  name: document.getElementById('customer-name').value,
  role: document.getElementById('customer-role').value,
  country: document.getElementById('customer-country').value
};
